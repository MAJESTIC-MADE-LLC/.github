# Support

Email [support@majesticmade.dev](mailto:support@majesticmade.dev) for product support. Include the
product, app version or build, device/platform, and a short description of the problem.

Do not send passwords, recovery material, payment details, personal records, child data, health
information, private documents, or full unredacted logs. Share only the minimum information needed
to reproduce the problem.

A public GitHub issue is appropriate only for a reproducible, non-sensitive software defect in a
repository that accepts issues. Vulnerabilities and exposed secrets must use the private process in
[SECURITY.md](SECURITY.md), never a public issue.
