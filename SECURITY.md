# Security Policy

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability or exposed secret.

Email `support@majesticmade.dev` with `[SECURITY]` at the start of the subject. Include the affected
repository or product, impact, reproducible steps, and the smallest safe proof of concept. Remove
personal data, production credentials, child data, private documents, and unrelated records.

We will acknowledge a usable report, investigate it, and coordinate disclosure when a fix is ready.
Please do not access other users' data, degrade a service, use social engineering, or retain data
you encounter while testing.

## Supported Software

The portfolio is pre-release. Only the latest code on a repository's `dev` branch is actively
maintained during development. Once a product ships, this file will list its supported release
versions and security-update policy.

## Secrets

If a live credential is found, stop using it and report it immediately. Include the file and line
or commit identifier, but do not paste the credential into email, an issue, or a screenshot.
